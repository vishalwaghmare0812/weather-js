# Weather
A clean and interactive web site built with vanilla JavaScript that fetches real-time weather information using the OpenWeatherMap API.

## Features
- Real-Time Data: Fetches live weather conditions for any city worldwide.
- Dynamic Emojis: Automatically displays weather-specific emojis (like ☀️, 🌧️, ❄️, ⛈️) based on OpenWeatherMap condition IDs.
- Temperature Conversion: Converts Kelvin data from the API into Celsius automatically.
- Input Validation & Error Handling: Gracefully handles invalid city names (404 errors) and empty inputs with custom error displays.
- Asynchronous JavaScript: Uses async/await and the Fetch API for smooth data retrieval without reloading the page.
